# Roadmap

Ledgerline advances **observability, evidence quality, and owner review before authority**. The roadmap is directional. It does not authorise live trading, signing, custody, wallet operation, or venue access.

## Completed

| Area | Delivered capability |
| --- | --- |
| Mission Control | Agent-first operating view for research posture, current work, task attention, policy/account posture, and audit trace. |
| Agent Room | Supervisor and selected-specialist research conversations with visible, bounded context. |
| Scoped memory | Owner-scoped shared memory, private per-agent memory, explicit promotion review, expiry/status filtering, and audit actions. |
| Research governance | Server-defined protected roles, capability bindings, policy-aware research, paper proposals, and immutable activity. |
| Security boundary | Compile-time sealed venue mutation boundary, fail-closed live paths, stable upstream error handling, and owner isolation tests. |
| Engineering quality | Node.js 24 CI, Docker-image verification, tests, type checks, builds, dependency audit, and branch-to-staging workflow. |

## In progress

The immediate priorities are authenticated mobile review of the Agent Room workspace, clearer evidence provenance, richer task hand-offs, and owner-facing memory lifecycle ergonomics. This work remains within research, review, and paper-operation boundaries.

## Future only

Any real-capital capability is a separate programme, not a feature flag. It requires a dedicated environment, independent security review, cloud-grade key management, reconciliation design, incident controls, testnet verification, human approval controls, legal/compliance assessment, small-capital pilot governance, and separate written GO authority. The current state remains **NO-GO for real capital**.
