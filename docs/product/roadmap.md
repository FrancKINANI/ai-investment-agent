# Roadmap

Ledgerline will continue to increase **observability and review quality** before authority. The PAIA v0.4 foundation now adds a validated Capability Registry: every declared research capability has a stable identifier, version, safe scope, and role binding. The roadmap is directional and does not authorize live trading.

1. **Capability governance:** extend the versioned registry only through validated manifests, visible role bindings, audit identifiers, and policy-safe scopes.
2. **Evidence quality:** richer provenance, clearer research completeness, and owner review summaries.
3. **Simulation fidelity:** stronger paper-proposal lifecycle coverage and scenario analysis without venue access.
4. **Operator ergonomics:** accessible loading, contrast, mobile navigation, and traceable activity review.
5. **Restricted integrations:** only after documented scope isolation, revocation, simulation coverage, owner mandate, and security review.

No capability manifest can add credentials, wallet keys, signing authority, custody, withdrawal permissions, live execution, or live venue access. Any future real capability would require a separate product decision, independent security design, explicit owner consent, and server-enforced controls. It is not on the current implementation path.
