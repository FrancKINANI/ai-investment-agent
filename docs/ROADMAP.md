# Roadmap

Ledgerline will continue to increase **observability and review quality** before authority. The roadmap is directional and does not authorize live trading.

1. **Evidence quality:** richer provenance, clearer research completeness, and owner review summaries.
2. **Simulation fidelity:** stronger paper-proposal lifecycle coverage and scenario analysis without venue access.
3. **Operator ergonomics:** accessible loading, contrast, mobile navigation, and traceable activity review.
4. **Restricted integrations:** only after documented scope isolation, revocation, simulation coverage, owner mandate, and security review.

Any future real capability would require a separate product decision, independent security design, explicit owner consent, and server-enforced controls. It is not on the current implementation path.
